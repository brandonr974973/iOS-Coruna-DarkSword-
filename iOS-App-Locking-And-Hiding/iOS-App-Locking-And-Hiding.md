## 1. 应用锁定与隐藏的需求背景

### 1.1 隐私保护的多层需求

在移动设备日益成为个人生活中心的今天，iOS 设备承载着大量敏感信息。应用锁定与隐藏的需求来自多个层面：

**个人隐私保护**

- 防止他人借用设备时查看敏感应用
- 保护金融、健康、社交等私密应用
- 避免公共场合被窥屏
- 保护个人照片和通信记录

**家庭共享场景**

- 家长控制儿童使用特定应用
- 防止儿童误操作付费应用
- 限制社交媒体使用时间
- 保护成人应用不被儿童发现

**企业安全需求**

- 保护企业应用和数据
- 防止未授权访问商业信息
- 满足合规要求
- 设备丢失时的数据保护

**共享设备场景**

- 多人共用一台设备
- 临时借出设备时的隐私保护
- 演示设备的内容保护
- 公共终端的安全控制

### 1.2 iOS 隐私保护的演进

Apple 在隐私保护方面持续投入，iOS 的隐私功能经历了显著的演进：

**iOS 7（2013）**

- 引入 Touch ID
- 应用内密码保护
- 基本的通知隐私

**iOS 13（2019）**

- 引入 Face ID 支持第三方应用
- 隐藏的相册功能
- 锁定的备忘录

**iOS 14（2020）**

- App Library 整理应用
- 通知隐私增强
- 指示器显示摄像头/麦克风使用

**iOS 16（2022）**

- 锁定模式
- 安全令牌
- 通行证密钥支持

**iOS 17（2023）**

- 高级数据保护
- 安全密码共享
- 敏感内容警告

**iOS 18（2024）**

- 原生应用锁定（Face ID/Touch ID）
- 隐藏应用功能
- 增强的隐私控制

### 1.3 威胁模型分析

应用锁定与隐藏需要防御的威胁：

**物理访问威胁**

| 威胁 | 风险等级 | 防御方式 |
|------|---------|---------|
| 他人借用设备查看 | 中 | 应用锁定 |
| 设备丢失/被盗 | 高 | 设备密码 + 应用锁 |
| 公共场合窥屏 | 中 | 隐藏应用 + 通知隐私 |
| 熟人恶意访问 | 中高 | Face ID/Touch ID 锁定 |

**远程威胁**

| 威胁 | 风险等级 | 防御方式 |
|------|---------|---------|
| 恶意应用访问数据 | 高 | 沙箱隔离 + 权限控制 |
| 网络攻击 | 高 | 加密 + 安全通信 |
| 云数据泄露 | 中 | 端到端加密 |

## 2. iOS 原生应用锁定机制

### 2.1 iOS 18 原生应用锁定

iOS 18 引入了期待已久的原生应用锁定功能，这是 iOS 隐私保护的重大进步。

**功能概述**

从 iOS 18 开始，用户可以直接使用 Face ID 或 Touch ID 锁定任何应用：

```
锁定步骤：
1. 在主屏幕长按要锁定的应用图标
2. 在弹出菜单中选择"需要 Face ID"（或"需要 Touch ID"）
3. 确认锁定
4. 应用图标变暗并显示锁定图标
5. 打开应用时需要生物识别认证
```

**支持的设备**

- iPhone XS 及更新机型（Face ID）
- iPhone SE 第 2 代及更新机型（Touch ID）
- iPad Pro（Face ID 机型）
- iPad Air 第 3 代及更新机型（Touch ID）

**锁定效果**

- 应用图标变暗，显示锁定图标
- 打开应用需要 Face ID/Touch ID 认证
- 通知内容被隐藏
- 应用预览被模糊化
- Siri 无法访问应用内容

### 2.2 锁定前的应用状态

在 iOS 18 之前，iOS 没有原生的应用锁定功能。用户需要依赖以下方式：

**应用内锁定**

许多应用自带锁定功能：
- 银行应用：需要密码或生物识别
- 密码管理器：需要主密码
- 加密通信应用：需要 PIN 码
- 健康应用：需要 Face ID/Touch ID

**快捷指令自动化**

通过快捷指令创建自动化锁定：
- 打开应用时触发认证
- 使用"打开应用"动作配合密码提示
- 需要一定的技术知识

**屏幕使用时间**

使用屏幕使用时间的限制功能：
- 设置应用使用时间限制
- 通过密码解除限制
- 间接实现应用锁定效果

### 2.3 原生锁定的技术实现

iOS 18 应用锁定的技术原理：

**系统级集成**

```
应用锁定架构：
├── SpringBoard（主屏幕管理器）
│   ├── 应用图标状态管理
│   ├── 锁定状态显示
│   └── 认证请求触发
├── BiometricKit（生物识别框架）
│   ├── Face ID 认证
│   ├── Touch ID 认证
│   └── 认证结果回调
├── 应用进程
│   ├── 启动拦截
│   ├── 认证等待
│   └── 认证后恢复
└── 通知系统
    ├── 通知内容过滤
    └── 敏感信息隐藏
```

**安全机制**

- 锁定状态存储在 Secure Enclave 中
- 认证请求由系统级服务处理
- 应用本身无法绕过锁定
- 锁定状态在重启后保持

### 2.4 锁定应用的管理

管理已锁定的应用：

**查看锁定状态**

- 锁定的应用图标显示锁定标志
- 在设置中查看锁定应用列表
- 通过长按图标查看锁定选项

**解除锁定**

```
解除步骤：
1. 长按已锁定的应用图标
2. 选择"不需要 Face ID"（或"不需要 Touch ID"）
3. 确认解除
4. 应用恢复正常状态
```

**批量管理**

- 可以一次锁定多个应用
- 可以一次解除多个应用的锁定
- 锁定状态可以通过 iCloud 同步（可选）

### 2.5 原生锁定的限制

iOS 18 原生应用锁定的已知限制：

**功能限制**

- 无法锁定系统设置中的特定页面
- 无法锁定通知中心的内容
- 无法锁定 Spotlight 搜索结果
- 无法锁定 Siri 的建议

**兼容性限制**

- 仅支持 iOS 18 及以上版本
- 需要支持 Face ID 或 Touch ID 的设备
- 某些企业应用可能有自己的锁定逻辑

**安全限制**

- 如果设备密码被泄露，锁定可能被绕过
- 无法防御内核级攻击
- 无法防御物理提取（需要专业设备）

## 3. iOS 18 隐藏应用功能详解

### 3.1 隐藏应用功能概述

iOS 18 引入了隐藏应用功能，允许用户将敏感应用从主屏幕和 App Library 中隐藏。

**功能特点**

- 隐藏的应用不在主屏幕显示
- 隐藏的应用不在 App Library 显示
- 隐藏的应用不在 Spotlight 搜索结果显示
- 隐藏的应用不在 Siri 建议中显示
- 隐藏的应用需要 Face ID/Touch ID 才能访问

**隐藏步骤**

```
隐藏步骤：
1. 长按要隐藏的应用图标
2. 选择"需要 Face ID"
3. 在弹出选项中选择"隐藏并需要 Face ID"
4. 确认隐藏
5. 应用移动到"隐藏的应用"文件夹
6. 该文件夹需要 Face ID 才能打开
```

### 3.2 隐藏的应用文件夹

隐藏的应用被放置在一个特殊的文件夹中：

**文件夹特性**

- 名称为"隐藏的应用"（Hidden Apps）
- 位于主屏幕最后一页
- 文件夹本身需要 Face ID/Touch ID 才能打开
- 文件夹内的应用已经锁定

**文件夹行为**

```
文件夹行为：
├── 默认状态：显示为模糊的锁定文件夹
├── 认证前：无法查看内容
├── 认证后：显示所有隐藏的应用
└── 关闭后：自动重新锁定
```

### 3.3 隐藏应用的效果

隐藏应用在系统中的表现：

**主屏幕**

- 应用图标不显示
- 应用小组件不显示
- 应用文件夹中不显示

**App Library**

- 应用不出现在任何分类中
- 搜索时不显示
- 建议中不显示

**Spotlight 搜索**

- 搜索应用名称不显示结果
- 搜索应用内容不显示结果
- 搜索建议中不显示

**Siri**

- Siri 无法打开隐藏的应用
- Siri 无法提供隐藏应用的建议
- Siri 无法访问隐藏应用的数据

**通知**

- 通知内容被隐藏
- 通知预览不显示
- 通知数量不显示（可选）

### 3.4 访问隐藏的应用

访问隐藏应用的方式：

**方式一：通过隐藏文件夹**

```
访问步骤：
1. 滑动到主屏幕最后一页
2. 找到"隐藏的应用"文件夹
3. 点击文件夹
4. 使用 Face ID/Touch ID 认证
5. 文件夹打开，显示所有隐藏的应用
6. 点击要使用的应用
```

**方式二：通过设置**

```
访问步骤：
1. 打开"设置"应用
2. 进入"Face ID 与密码"（或"Touch ID 与密码"）
3. 查看已锁定和隐藏的应用列表
4. 管理锁定和隐藏状态
```

### 3.5 取消隐藏应用

取消隐藏应用的步骤：

```
取消隐藏步骤：
1. 打开"隐藏的应用"文件夹（需要 Face ID）
2. 长按要取消隐藏的应用图标
3. 选择"不需要 Face ID"
4. 选择"取消隐藏"
5. 应用恢复到主屏幕正常位置
```

### 3.6 隐藏应用的限制

隐藏应用功能的限制：

**系统应用限制**

- 部分系统应用无法隐藏（如电话、信息、设置）
- 系统服务相关应用无法隐藏
- 核心功能应用无法隐藏

**第三方应用限制**

- 某些应用可能不支持隐藏（如系统级应用）
- 企业应用可能有自己的管理策略
- 某些应用的小组件可能无法隐藏

**搜索限制**

- 隐藏的应用在搜索中不可见
- 但应用的设置可能在设置搜索中可见
- 应用的数据可能在某些系统搜索中可见

## 4. Face ID 与 Touch ID 应用锁

### 4.1 Face ID 技术原理

Face ID 是 Apple 的面部识别系统，用于应用锁定：

**技术架构**

```
Face ID 架构：
├── TrueDepth 摄像头系统
│   ├── 红外摄像头
│   ├── 点阵投影器
│   └── 泛光感应器
├── A 系列芯片的神经网络引擎
│   ├── 面部特征提取
│   ├── 深度图分析
│   └── 匹配算法
└── Secure Enclave
    ├── 面部数据存储
    ├── 匹配决策
    └── 认证结果
```

**安全特性**

- 面部数据存储在 Secure Enclave 中
- 面部数据不会上传到 Apple 服务器
- 面部数据不会包含在备份中
- 每次认证都是本地处理

### 4.2 Touch ID 技术原理

Touch ID 是 Apple 的指纹识别系统：

**技术架构**

```
Touch ID 架构：
├── 指纹传感器
│   ├── 蓝宝石晶体覆盖
│   ├── 电容式触摸感应
│   └── 不锈钢检测环
├── A 系列芯片的安全区域
│   ├── 指纹图像提取
│   ├── 特征点分析
│   └── 匹配算法
└── Secure Enclave
    ├── 指纹数据存储
    ├── 匹配决策
    └── 认证结果
```

**安全特性**

- 指纹数据存储在 Secure Enclave 中
- 指纹数据不会上传到 Apple 服务器
- 指纹数据不会包含在备份中
- 实际指纹图像不会保存，只保存数学表示

### 4.3 生物识别与应用锁

生物识别在应用锁定中的应用：

**认证流程**

```
应用锁定认证流程：
1. 用户点击锁定的应用
2. 系统弹出 Face ID/Touch ID 认证请求
3. 用户进行面部识别或指纹识别
4. Secure Enclave 验证生物特征
5. 验证成功，应用启动
6. 验证失败，提示重试或使用密码
```

**降级机制**

- 如果生物识别失败多次，要求输入设备密码
- 设备重启后首次需要输入密码
- 48 小时未解锁设备需要输入密码
- 远程锁定后需要输入密码

### 4.4 生物识别的安全性

生物识别在应用锁定中的安全性评估：

**Face ID 安全性**

- 误识率：1/1,000,000
- 支持注意力检测（需要睁眼注视）
- 支持遮挡检测（口罩、墨镜）
- 支持双胞胎检测（需要额外设置）

**Touch ID 安全性**

- 误识率：1/50,000
- 支持多指纹注册（最多 5 个）
- 支持活体检测
- 指纹数据加密存储

**安全建议**

- 注册自己的生物特征
- 不要注册他人的生物特征
- 定期更新生物特征数据
- 在敏感场景使用密码替代

### 4.5 生物识别的局限性

生物识别在应用锁定中的局限性：

**强制解锁场景**

- 法律强制要求解锁
- 执法部门要求解锁
- 紧急情况下被强制解锁

**生物特征泄露**

- 面部照片可能被用于攻击（Face ID 有防护）
- 指纹可能被复制（Touch ID 有活体检测）
- 生物特征一旦泄露无法更改

**特殊情况**

- 面部变化（手术、受伤）可能影响识别
- 手指受伤或湿润可能影响识别
- 口罩、墨镜等遮挡物可能影响识别

## 5. 需要密码的访问控制

### 5.1 设备密码与应用锁

设备密码在应用锁定中的角色：

**设备密码类型**

- 6 位数字密码（默认）
- 4 位数字密码（不推荐）
- 自定义数字密码
- 自定义字母数字密码

**密码强度对比**

| 密码类型 | 组合数 | 暴力破解时间 | 推荐程度 |
|---------|--------|------------|---------|
| 4 位数字 | 10,000 | 秒级 | 不推荐 |
| 6 位数字 | 1,000,000 | 分钟级 | 基本 |
| 8 位数字 | 100,000,000 | 小时级 | 推荐 |
| 字母数字（8位） | 数万亿 | 年级 | 强烈推荐 |

### 5.2 密码保护的应用

iOS 中使用密码保护的应用和功能：

**系统应用**

- 设置：需要密码修改敏感设置
- 健康：需要 Face ID/密码访问
- 钱包：需要 Face ID/密码访问
- 密码与密钥：需要 Face ID/密码访问

**第三方应用**

- 银行应用：通常需要密码或生物识别
- 密码管理器：需要主密码
- 加密通信：需要 PIN 码或密码
- 文件管理：可以设置密码

### 5.3 密码管理策略

管理应用密码的最佳策略：

**策略一：使用密码管理器**

- 使用 iCloud 钥匙串或第三方密码管理器
- 为每个应用生成强密码
- 避免重复使用密码
- 定期更新密码

**策略二：生物识别优先**

- 优先使用 Face ID/Touch ID
- 设置强设备密码作为后备
- 在敏感场景使用密码
- 定期更新生物特征数据

**策略三：分级保护**

```
分级保护策略：
├── 高敏感应用（银行、密码管理器）
│   └── 生物识别 + 应用内密码
├── 中敏感应用（邮件、社交）
│   └── 生物识别锁定
├── 低敏感应用（新闻、天气）
│   └── 无需锁定
└── 隐藏应用（私密应用）
    └── 隐藏 + 生物识别锁定
```

### 5.4 密码恢复与重置

密码丢失时的恢复方案：

**设备密码丢失**

```
恢复步骤：
1. 连接设备到电脑
2. 进入恢复模式
3. 在 Finder/iTunes 中恢复设备
4. 从备份恢复数据
5. 重新设置密码

注意：如果未备份，数据将丢失
```

**应用密码丢失**

- 使用密码恢复功能
- 使用备用认证方式
- 联系应用支持
- 重新安装应用（可能丢失数据）

### 5.5 密码安全最佳实践

密码安全的最佳实践：

**创建强密码**

- 至少 8 位字符
- 混合大小写字母、数字和符号
- 避免使用个人信息
- 避免使用常见词汇

**管理密码**

- 使用密码管理器
- 不重复使用密码
- 定期更新密码
- 不共享密码

**保护密码**

- 不在公共场合输入密码
- 不在不安全的地方存储密码
- 警惕键盘记录器
- 启用双因素认证

## 6. 快捷指令自动化锁定

### 6.1 快捷指令概述

快捷指令（Shortcuts）是 iOS 的自动化工具，可以创建自定义工作流：

**快捷指令能力**

- 自动化日常任务
- 组合多个应用功能
- 响应系统事件
- 创建自定义操作

**与应用锁定的关系**

在 iOS 18 之前，快捷指令是实现应用锁定的主要方式之一。

### 6.2 创建应用锁定快捷指令

使用快捷指令创建应用锁定：

**基本锁定流程**

```
快捷指令设计：
1. 触发条件：打开特定应用
2. 动作：显示密码输入提示
3. 验证：检查输入的密码
4. 成功：继续打开应用
5. 失败：取消操作或显示警告
```

**实现步骤**

```
步骤 1：创建快捷指令
- 打开"快捷指令"应用
- 点击"+"创建新快捷指令
- 命名为"锁定[应用名称]"

步骤 2：添加动作
- 添加"要求输入"动作
- 设置输入类型为"密码"
- 设置提示文本

步骤 3：添加验证
- 添加"如果"动作
- 设置条件为输入等于预设密码
- 在"如果"分支添加"打开 URL"动作
- 在"否则"分支添加"显示警告"动作

步骤 4：设置自动化
- 创建个人自动化
- 触发条件：打开特定应用
- 运行快捷指令
```

### 6.3 高级自动化锁定

更复杂的自动化锁定方案：

**基于时间的锁定**

```
自动化设计：
- 工作时间（9:00-18:00）：锁定社交应用
- 休息时间（18:00-22:00）：锁定工作应用
- 夜间（22:00-9:00）：锁定所有非必要应用
```

**基于位置的锁定**

```
自动化设计：
- 在家：不锁定任何应用
- 在公司：锁定社交和娱乐应用
- 在公共场所：锁定所有敏感应用
```

**基于连接的锁定**

```
自动化设计：
- 连接到车载蓝牙：锁定消息应用
- 连接到蓝牙耳机：锁定音乐应用
- 连接到 AirPlay：锁定视频应用
```

### 6.4 快捷指令锁定的限制

快捷指令锁定的局限性：

**安全限制**

- 密码存储在快捷指令中，可能被提取
- 无法使用生物识别
- 可以被绕过（强制关闭快捷指令）
- 不如系统级锁定安全

**功能限制**

- 无法锁定系统应用
- 无法隐藏应用图标
- 无法保护通知内容
- 无法阻止 Spotlight 搜索

**用户体验**

- 每次打开应用都需要运行快捷指令
- 可能有延迟
- 可能被用户忽略或禁用
- 需要手动设置和维护

### 6.5 快捷指令与其他方案对比

快捷指令锁定与其他方案的对比：

| 方案 | 安全性 | 易用性 | 灵活性 | 推荐场景 |
|------|--------|--------|--------|---------|
| iOS 18 原生锁定 | 高 | 高 | 中 | 日常使用 |
| 快捷指令锁定 | 中 | 低 | 高 | 自定义需求 |
| 应用内锁定 | 高 | 中 | 低 | 特定应用 |
| 屏幕使用时间 | 中 | 中 | 中 | 家长控制 |

## 7. 屏幕使用时间与应用限制

### 7.1 屏幕使用时间概述

屏幕使用时间（Screen Time）是 iOS 的数字健康管理工具：

**核心功能**

- 应用使用时间统计
- 应用使用时间限制
- 内容与隐私访问控制
- 停用时间
- 始终允许的应用

### 7.2 应用使用时间限制

使用屏幕使用时间限制应用：

**设置步骤**

```
设置步骤：
1. 打开"设置" → "屏幕使用时间"
2. 启用屏幕使用时间（如果未启用）
3. 设置屏幕使用时间密码
4. 点击"应用限额"
5. 点击"添加限额"
6. 选择要限制的应用或类别
7. 设置每日时间限制
8. 点击"添加"
```

**限制效果**

- 达到时间限制后，应用图标变暗
- 打开应用时显示时间已到提示
- 需要输入屏幕使用时间密码才能继续使用
- 可以请求更多时间

### 7.3 停用时间

使用停用时间限制应用访问：

**设置步骤**

```
设置步骤：
1. 打开"设置" → "屏幕使用时间"
2. 点击"停用时间"
3. 启用停用时间
4. 设置停用时间段（如 22:00-7:00）
5. 选择"始终允许"的应用
```

**停用效果**

- 在停用时间段内，只有"始终允许"的应用可以使用
- 其他应用显示为灰色且无法打开
- 需要输入密码才能使用受限应用
- 电话和消息默认始终允许

### 7.4 内容与隐私访问控制

使用内容与隐私访问控制限制功能：

**设置步骤**

```
设置步骤：
1. 打开"设置" → "屏幕使用时间"
2. 点击"内容与隐私访问控制"
3. 启用内容与隐私访问控制
4. 配置各项限制
```

**可用限制**

- iTunes 与 App Store 购买
- 内容限制（年龄分级）
- 隐私设置（位置、联系人等）
- 允许的应用（系统应用）

### 7.5 屏幕使用时间作为应用锁

将屏幕使用时间用作应用锁定：

**实现方式**

```
锁定策略：
1. 设置应用使用时间限制为 1 分钟
2. 达到限制后应用被锁定
3. 需要密码才能继续使用
4. 每次使用都需要输入密码
```

**优势**

- 系统级功能，无需第三方应用
- 可以设置时间限制
- 可以按类别限制
- 支持停用时间

**限制**

- 不是真正的锁定，而是时间限制
- 密码可能被他人知道
- 可以轻易绕过（输入密码）
- 不适合高安全需求

### 7.6 家长控制场景

屏幕使用时间在家长控制中的应用：

**儿童设备设置**

```
推荐设置：
├── 屏幕使用时间密码
│   └── 家长知道的密码
├── 应用限额
│   ├── 社交应用：每天 1 小时
│   ├── 游戏应用：每天 2 小时
│   └── 教育应用：无限制
├── 停用时间
│   └── 21:00-7:00（睡眠时间）
├── 内容与隐私
│   ├── 禁止应用内购买
│   ├── 限制成人内容
│   └── 限制位置共享
└── 始终允许
    ├── 电话
    ├── 信息
    └── 教育应用
```

### 8.1 引导式访问概述

引导式访问（Guided Access）是 iOS 的单一应用模式：

**功能目的**

- 将设备锁定在单个应用中
- 限制应用的特定功能
- 防止用户退出应用
- 适用于演示、教育、公共终端等场景

### 8.2 启用引导式访问

启用和配置引导式访问：

**启用步骤**

```
启用步骤：
1. 打开"设置" → "辅助功能"

4. 设置"密码设置"

**使用步骤**

```
使用步骤：
1. 打开要锁定的应用
2. 连按三次侧边按钮（或 Home 按钮）
3. 配置引导式访问选项
4. 点击"开始"

- 禁用触摸（特定区域）

**功能控制**

- 禁用触摸（整个屏幕或特定区域）
- 限制屏幕区域
- 禁用时间控制
- 禁用辅助功能

**外观控制**

- 显示时钟
- 显示自动锁定
- 显示语音控制

引导式访问的典型应用场景：

设置：

## 9. 通知隐私与应用保护

### 9.1 通知隐私的重要性

通知是应用隐私的重要泄露点：

**通知泄露的风险**

- 锁屏显示敏感信息
- 他人看到通知内容
- 通知历史被查看
- 通知声音暴露活动

### 9.2 iOS 通知隐私设置

iOS 的通知隐私设置：

**锁屏通知**

```
设置路径：
设置 → 通知 → 显示预览

选项：
├── 始终：所有通知显示内容
├── 解锁时：仅设备解锁后显示内容
└── 从不：永不显示内容
```

**应用级通知控制**

```
每个应用的通知设置：
├── 允许通知
├── 通知位置
│   ├── 锁定屏幕
│   ├── 通知中心
│   └── 横幅
├── 显示预览
│   ├── 始终
│   ├── 解锁时
│   └── 从不
└── 声音和标记
```

### 9.3 锁定应用的通知保护

锁定应用的通知保护机制：

**iOS 18 锁定应用的通知**

- 锁定应用的通知内容被隐藏
- 通知预览显示"通知"而非具体内容
- 需要 Face ID 才能查看完整通知
- 通知数量可以隐藏

**通知保护效果**

```
锁定应用通知：
├── 锁屏显示
│   └── "[应用名称] 通知"（无内容）
├── 通知中心
│   └── "[应用名称] 通知"（无内容）
├── 横幅
│   └── "[应用名称] 通知"（无内容）
└── 解锁后
    └── 显示完整内容
```

### 9.4 敏感应用的通知策略

为敏感应用配置通知策略：

**高敏感应用（银行、健康）**

```
推荐设置：
├── 锁定屏幕：关闭
├── 通知中心：关闭
├── 横幅：临时
├── 显示预览：从不
└── 声音：关闭（可选）
```

**中敏感应用（邮件、消息）**

```
推荐设置：
├── 锁定屏幕：开启
├── 通知中心：开启
├── 横幅：临时
├── 显示预览：解锁时
└── 声音：开启
```

**低敏感应用（新闻、天气）**

```
推荐设置：
├── 锁定屏幕：开启
├── 通知中心：开启
├── 横幅：持续
├── 显示预览：始终
└── 声音：开启
```

### 9.5 通知定时推送

使用通知定时推送保护隐私：

**功能说明**

- 通知在特定时间汇总推送
- 减少实时通知的干扰
- 在私密时间查看通知

**设置步骤**

```
设置步骤：
1. 打开"设置" → "通知"
2. 点击"定时推送"
3. 启用"定时推送"
4. 设置推送时间（如每小时）
5. 选择要汇总的应用
```

### 9.6 通知隐私最佳实践

通知隐私的最佳实践：

**通用建议**

- 将"显示预览"设置为"解锁时"或"从不"
- 为敏感应用关闭锁屏通知
- 定期清理通知中心
- 使用通知定时推送

**高隐私需求**

- 所有应用"显示预览"设为"从不"
- 敏感应用关闭所有通知位置
- 使用通知摘要
- 启用锁定模式

## 10. 第三方应用锁定方案

### 10.1 第三方应用锁概述

在 iOS 18 之前，第三方应用锁是主要的应用锁定方案：

**第三方应用锁类型**

- 应用锁保险箱
- 密码管理器内置锁
- 文件加密应用
- 照片保险箱应用

### 10.2 知名第三方应用锁

知名的第三方应用锁定方案：

**AppLock（应用锁）**

- 功能：锁定任何应用
- 认证：密码、图案、Touch ID
- 特点：入侵者自拍、假封面
- 限制：无法真正锁定系统应用

**Folder Lock（文件夹锁）**

- 功能：加密和锁定文件
- 认证：密码、Touch ID
- 特点：内置浏览器、相机
- 限制：只能锁定文件，不能锁定应用

**Private Photo Vault（私密照片保险箱）**

- 功能：加密照片和视频
- 认证：密码、Touch ID、Face ID
- 特点：伪装图标、入侵者自拍
- 限制：只能锁定媒体文件

### 10.3 第三方方案的工作原理

第三方应用锁的工作原理：

**技术限制**

- iOS 沙箱隔离阻止应用锁定其他应用
- 第三方应用无法直接控制系统行为
- 只能通过间接方式实现锁定效果

**实现方式**

```
间接锁定方式：
├── 应用内保险箱
│   └── 在应用内存储和保护数据
├── 快捷指令集成
│   └── 通过快捷指令触发锁定
├── 屏幕使用时间集成
│   └── 利用系统限制功能
└── 设备配置文件
    └── 通过 MDM 配置文件限制
```

### 10.4 第三方方案的安全评估

第三方应用锁方案的安全性评估：

**安全优势**

- 提供额外的保护层
- 某些应用提供入侵检测
- 可以伪装和保护敏感数据
- 某些应用提供加密功能

**安全限制**

- 无法真正锁定系统应用
- 可能被绕过（强制关闭、卸载）
- 数据可能未加密或加密弱
- 依赖应用开发者的安全实践

**与原生方案对比**

| 特性 | 第三方方案 | iOS 18 原生 |
|------|-----------|------------|
| 系统级锁定 | 否 | 是 |
| 生物识别 | 部分支持 | 完全支持 |
| 安全性 | 中 | 高 |
| 兼容性 | 需要 iOS 版本 | iOS 18+ |
| 推荐度 | iOS 18 前推荐 | iOS 18+ 首选 |

### 10.5 iOS 18 后的第三方方案

iOS 18 原生锁定后的第三方方案定位：

**仍然有价值的功能**

- 入侵者自拍
- 伪装图标和界面
- 内置加密存储
- 假密码功能
- 多用户支持

**推荐组合**

```
推荐组合（iOS 18+）：
├── 系统级锁定
│   └── iOS 18 原生应用锁定
├── 增强功能
│   └── 第三方应用的入侵检测
└── 数据加密
    └── 第三方应用的加密存储
```

## 11. 照片与视频的锁定与隐藏

### 11.1 隐藏相册

iOS 原生的隐藏相册功能：

**功能说明**

- 将照片和视频从"照片"应用中隐藏
- 移动到"隐藏"相册
- iOS 16+ 需要 Face ID/密码访问

**隐藏步骤**

```
隐藏步骤：
1. 打开"照片"应用
2. 选择要隐藏的照片或视频
3. 点击"..."按钮
4. 选择"隐藏"
5. 确认隐藏
6. 照片移动到"隐藏"相册
```

**访问隐藏相册**

```
访问步骤：
1. 打开"照片"应用
2. 点击"相册"标签
3. 滚动到"更多相册"
4. 点击"隐藏"
5. 使用 Face ID/Touch ID 认证
6. 查看隐藏的照片和视频
```

### 11.2 锁定隐藏相册

iOS 16+ 对隐藏相册的锁定：

**锁定机制**

- 隐藏相册默认需要 Face ID/Touch ID
- 需要设备密码作为后备
- 锁定状态在重启后保持
- 无法通过设置禁用锁定

**安全效果**

- 隐藏相册不在"照片"应用中直接显示
- 访问需要生物识别认证
- 通知中不显示隐藏相册内容
- iCloud 同步时加密

### 11.3 已删除最近删除

"最近删除"相册的保护：

**功能说明**

- 删除的照片保留 30 天
- 可以恢复删除的照片
- iOS 16+ 需要 Face ID/密码访问

**安全设置**

```
设置步骤：
1. 打开"设置" → "照片"
2. 启用"需要 Face ID"（或 Touch ID）
3. "最近删除"相册被锁定
```

### 11.4 第三方照片保险箱

第三方照片保险箱应用：

**功能特点**

- 加密存储照片和视频
- 密码或生物识别保护
- 伪装图标和界面
- 入侵者自拍
- 云备份支持

**知名应用**

- Keepsafe
- Private Photo Vault
- Calculator Vault（伪装为计算器）
- Gallery Vault

### 11.5 照片隐私最佳实践

照片和视频隐私的最佳实践：

**基本保护**

- 使用隐藏相册功能
- 启用"最近删除"锁定
- 设置强设备密码
- 启用 Face ID/Touch ID

|---------|--------|------|---------|
| 机会主义 | 朋友/家人 | 低 | 基本锁定 |
| 熟人攻击 | 认识的人 | 中 | 生物识别锁定 |
| 物理攻击 | 小偷/攻击者 | 高 | 设备密码 + 锁定 |
| 法证提取 | 执法部门 | 极高 | 端到端加密 |

### 14.2 锁定方案安全对比

不同锁定方案的安全性对比：

### 14.3 攻击向量分析

应用锁定可能面临的攻击向量：

** shoulder surfing（窥屏）**

- 观察密码输入
- 观察图案解锁
- 防御：使用生物识别、遮挡输入

**强制解锁**

- 物理强迫解锁设备
- 法律强制要求解锁
- 防御：使用强密码、了解法律权利

**技术攻击**

- 利用漏洞绕过锁定
- 使用法证工具提取数据
- 防御：保持系统更新、使用加密

**社会工程**

- 欺骗用户透露密码
- 伪装成技术支持
- 防御：安全意识培训、不共享密码

### 14.4 安全最佳实践

应用锁定的安全最佳实践：

**多层防御**

```
多层防御策略：
├── 第一层：设备密码
│   └── 强密码、生物识别
├── 第二层：应用锁定
│   └── iOS 18 原生锁定
├── 第三层：应用内安全
│   └── 应用内密码、加密
└── 第四层：数据加密
    └── 端到端加密、安全备份
```

**定期审查**

- 定期审查锁定设置
- 更新密码和生物特征
- 检查锁定应用列表
- 审查安全事件

**应急响应**

- 设备丢失时立即远程锁定
- 使用"查找我的"定位设备
- 必要时远程擦除设备
- 更改所有重要密码

### 14.5 安全误区

应用锁定的常见安全误区：

**误区一：锁定等于加密**

- 锁定只是访问控制
- 数据可能未加密
- 需要额外的加密措施

**误区二：生物识别绝对安全**

- 生物识别可能被绕过
- 需要密码作为后备
- 生物特征一旦泄露无法更改

**误区三：锁定应用就安全了**

- 锁定只保护应用访问
- 数据可能在其他地方泄露
- 需要全面的安全策略
