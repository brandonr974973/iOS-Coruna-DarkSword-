## 1. 概述

### 1.1 WebKit 在 iOS 中的地位

WebKit 是 iOS 上唯一的浏览器引擎。Safari 以及所有第三方浏览器（Chrome、Firefox 等）在 iOS 上都必须使用 WebKit。这意味着 WebKit 的漏洞影响所有 iOS 用户，且是远程代码执行（RCE）的首要入口。

### 1.2 清单编制方法

本清单基于以下来源编制：
- Apple 安全更新公告（2018-2026）
- CVE 数据库中的 WebKit 相关条目
- Google Project Zero 的 WebKit 漏洞报告
- 越狱社区（palera1n、Dopamine 等）的公开研究
- Pwn2Own 竞赛中的 WebKit 漏洞
- WebKit 开源代码库的安全审计

### 1.3 风险等级定义

| 等级 | 定义 | 典型特征 |
|------|------|----------|
| **P0 - 严重** | 零点击 RCE 或沙箱逃逸 | 无需用户交互，远程可达 |
| **P1 - 高危** | 单击 RCE 或高价值信息泄露 | 需要少量用户操作 |
| **P2 - 中危** | 受限的代码执行或数据泄露 | 需要特定条件或配置 |
| **P3 - 低危** | DoS 或低风险信息泄露 | 影响有限 |

### 1.4 WebKit 进程架构

```
┌─────────────────────────────────────────────────┐
│  UI Process（正常沙箱）                           │
│  ├── WebContent Process（严格沙箱）               │
│  │   ├── WebCore（DOM/CSS/HTML）                 │
│  │   ├── JavaScriptCore（JSC）                   │
│  │   ├── WebGL/WebGPU                            │
│  │   ├── WebAssembly                             │
│  │   └── Media                                   │
│  ├── Network Process（网络沙箱）                   │
│  ├── GPU Process（图形沙箱）                       │
│  └── Storage Process（存储沙箱）                   │
└─────────────────────────────────────────────────┘
```

每个子进程都是独立的攻击目标。WebContent 是最核心的攻击面，因为它直接处理网页内容。

## 2. JavaScriptCore（JSC）引擎

### 2.1 组件概述

| 属性 | 值 |
|------|-----|
| **风险等级** | **P0 - 严重** |
| **攻击向量** | 远程（网页 JavaScript） |
| **用户交互** | 零点击（自动执行 JS） |
| **历史 CVE 数量** | 80+ |
| **利用影响力** | WebContent 沙箱内 RCE |

### 2.2 子组件清单

#### 2.2.1 DFG JIT 编译器

| 属性 | 值 |
|------|-----|
| **风险等级** | P0 |
| **漏洞类型** | 类型推断错误、优化不安全、类型检查省略 |
| **攻击难度** | 高（需要理解 JIT 优化逻辑） |
| **历史 CVE** | CVE-2021-30860、CVE-2023-28205、CVE-2023-32373 等 |

**攻击面特征**：
- DFG（Data Flow Graph）JIT 进行激进的类型推断优化
- 可能省略看似冗余的类型检查，导致类型混淆
- 是 WebKit 漏洞密度最高的子组件

**已知漏洞模式**：
- `Phantom` 节点的类型推断错误
- `ForwardPropagationPhase` 中的类型传播缺陷
- `CFA（Constant Folding Analysis）` 中的类型假设错误
- `OSR（On-Stack Replacement）` 入口的类型验证缺失

#### 2.2.2 FTL JIT 编译器

| 属性 | 值 |
|------|-----|
| **风险等级** | P0 |
| **漏洞类型** | 类型推断错误、寄存器分配错误、DCE 不安全 |
| **攻击难度** | 极高（需要理解 LLVM-based JIT） |
| **历史 CVE** | CVE-2022-22675、CVE-2023-41991 等 |

**攻击面特征**：
- FTL（Faster Than Light）JIT 基于 LLVM 后端
- 更激进的优化意味着更多的类型假设
- 漏洞一旦触发，利用原语更强大

**已知漏洞模式**：
- `DFG→FTL` 降级时的类型状态不一致
- `Dead Code Elimination` 错误删除有副作用的代码
- `Register Allocation` 中的生命周期错误
- `Speculative Optimization` 的去优化路径缺陷

#### 2.2.3 垃圾回收器（GC）

| 属性 | 值 |
|------|-----|
| **风险等级** | P1 |
| **漏洞类型** | UAF、Double-Free、并发 GC 竞态 |
| **攻击难度** | 中-高 |
| **历史 CVE** | CVE-2020-9818（相关）、多个未公开 |

**攻击面特征**：
- JSC 使用分代 GC（Young Generation + Old Generation）
- GC 触发时机不确定，可导致 UAF
- 并发 GC 引入竞态条件

**已知漏洞模式**：
- `MarkedBlock` 的回收竞态
- `WriteBarrier` 遗漏导致对象被过早回收
- `Conservative Scanning` 的误判
- `Incremental Sweeping` 中的状态不一致

#### 2.2.4 正则表达式引擎（Yarr）

| 属性 | 值 |
|------|-----|
| **风险等级** | P1 |
| **漏洞类型** | 堆溢出、栈溢出、ReDoS |
| **攻击难度** | 中 |
| **历史 CVE** | CVE-2019-8637（相关）、多个内部修复 |

**攻击面特征**：
- Yarr 是 WebKit 自定义的正则引擎
- 复杂正则表达式可能导致指数级回溯
- 正则编译和执行中的缓冲区管理

#### 2.2.5 WebAssembly（Wasm）运行时

| 属性 | 值 |
|------|-----|
| **风险等级** | P1 |
| **漏洞类型** | 类型验证错误、内存越界、整数溢出 |
| **攻击难度** | 高 |
| **历史 CVE** | CVE-2023-27943（相关） |

**攻击面特征**：
- Wasm 二进制格式的类型验证
- 线性内存的边界检查
- JIT 编译的 Wasm 代码

## 36. 攻击面优先级排序

### 36.1 远程攻击研究优先级

```

├── WebGPU             — 新 API，研究不足，攻击面大
└── Media/MSE          — 零点击，编解码器复杂

优先级 2：

优先级 3：
├── CSS Parser         — 缓冲区溢出模式
├── HTML Parser        — 状态机复杂性
├── SVG 滤镜          — 像素处理溢出

```

## 37. 研究策略建议

### 37.1 新手入门路径

1. **从开源 WebKit 开始**：阅读 WebKit 源码，理解架构
2. **分析已知 CVE**：复现和理解已公开的漏洞
3. **选择单一组件深入**：建议从 CSS Parser 或 SVG 开始
4. **使用模糊测试**：对选定的组件进行覆盖率引导的模糊测试
5. **逐步扩展**：掌握一个组件后扩展到其他组件

### 37.2 中级研究者策略

1. **聚焦 JSC JIT**：这是最高价值的目标
2. **补丁分析**：跟踪每个 WebKit 安全更新
3. **变体分析**：从一个 CVE 出发，寻找同类漏洞
4. **跨组件攻击**：研究组件间交互的漏洞
5. **自动化发现**：开发符号执行或 ML 辅助工具

### 37.3 高级研究者策略

1. **零日研究**：独立发现全新类型的漏洞
2. **完整 Exploit Chain**：从 WebKit RCE 到沙箱逃逸到内核提权
3. **缓解措施研究**：分析现有缓解措施的有效性
4. **新攻击面探索**：研究 WebGPU、WebNN 等新 API
5. **硬件-软件交互**：研究 GPU 驱动和 WebKit 的交互

### 37.4 工具推荐

| 工具 | 用途 | 适用组件 |
|------|------|---------|
| **libFuzzer** | 覆盖率引导模糊测试 | 所有解析器 |
| **IDA Pro / Ghidra** | 逆向分析 | 闭源组件 |
| **Frida** | 动态插桩 | 运行时分析 |
| **angr** | 符号执行 | JSC、IOKit |
| **WebKit JSC Shell** | JS 引擎测试 | JSC |
| **ClusterFuzz** | 分布式模糊测试 | 大规模测试 |
