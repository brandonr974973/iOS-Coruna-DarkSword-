## 2. 多点触控与手势操作

### 2.1 多点触控的革命

**技术突破**：

2007年，Apple首次将多点触控技术引入手机，彻底改变了人机交互方式：

**电容式触控**：
- 检测手指电容变化
- 支持多点同时触控
- 高精度定位

**触控采样率**：
- 早期：60Hz
- 现代：120Hz（ProMotion）
- 更低延迟
- 更流畅体验

**多点触控能力**：
- 支持最多10点触控
- 精确识别手势
- 低延迟响应

### 2.2 基础手势

**点击（Tap）**：
- 单指轻触
- 激活按钮、链接
- 打开应用

**长按（Long Press）**：
- 按住不放
- 显示上下文菜单
- 进入编辑模式
- 触发3D Touch/Haptic Touch

**滑动（Swipe）**：
- 单指滑动
- 滚动页面
- 切换标签
- 删除项目

**双指滑动**：
- 滚动长页面
- 在应用中导航

**捏合（Pinch）**：
- 双指捏合：缩小
- 双指张开：放大
- 缩放图片、地图、网页

**拖动（Drag）**：
- 长按后移动
- 移动图标
- 选择文本
- 拖放文件

### 2.3 系统级手势

**主屏幕手势**：

**从底部上滑**：
- 返回主屏幕
- 快速访问主屏幕
- 替代Home键

**从底部上滑并暂停**：
- 打开应用切换器
- 查看所有后台应用
- 快速切换应用

**从顶部下滑**：
- 打开通知中心
- 查看所有通知
- 查看今日视图

**从右上角下滑**：
- 打开控制中心
- 快速访问常用设置
- 调整亮度、音量

**从左边缘右滑**：
- 返回上一级
- 导航返回
- 替代返回按钮

### 2.4 应用内手势

**Safari**：
- 左右滑动：前进/后退
- 长按链接：预览
- 双指缩放：缩放页面

**照片**：
- 捏合：缩放照片
- 左右滑动：切换照片
- 上滑：查看详情

**地图**：
- 双指旋转：旋转地图
- 双指倾斜：3D视角
- 捏合：缩放地图

**邮件**：
- 左右滑动：删除/标记
- 下拉：刷新
- 长按：选择文本

### 2.5 高级手势

**3D Touch（已淘汰）**：
- 按压屏幕
- 显示快捷操作
- 预览内容
- 压力感应

**Haptic Touch（当前）**：

## 6. AirDrop与连续互通

### 6.1 AirDrop

**2011年（Mac）/ 2013年（iOS）**：

Apple推出AirDrop，实现设备间快速文件传输：

**技术原理**：

**蓝牙发现**：
- 蓝牙低功耗
- 发现附近设备
- 低电量消耗
- 快速配对

**Wi-Fi传输**：
- Wi-Fi直连
- 高速传输
- 无需网络
- 端到端加密

**工作流程**：
```
发送方选择文件
  ↓
蓝牙发现接收方
  ↓
建立Wi-Fi直连
  ↓
加密传输文件
  ↓
接收方确认接收
  ↓
传输完成
```

**支持的内容**：
- 照片和视频
- 文档
- 网页链接
- 位置信息
- 联系人
- 应用数据

**使用方式**：
```swift
// 分享文件
let activityViewController = UIActivityViewController(activityItems: [fileURL], applicationActivities: nil)
present(activityViewController, animated: true)

// 接收文件
// 自动弹出确认对话框
```

### 6.2 连续互通（Continuity）

**2014年**：

Apple推出连续互通，实现Apple设备间无缝协作：

**接力（Handoff）**：

在一个设备开始，在另一个设备继续：

**支持的应用**：
- Safari：继续浏览
- Mail：继续撰写
- Pages：继续编辑
- Maps：继续导航
- 第三方应用

**工作原理**：
```
设备A开始任务
  ↓
通过蓝牙广播
  ↓
设备B检测到
  ↓
显示接力图标
  ↓
用户点击继续
  ↓
任务转移到设备B
```

**通用剪贴板**：

在一个设备复制，在另一个设备粘贴：

**支持的内容**：
- 文本
- 图片
- 链接
- 文件

**安全机制**：
- 端到端加密
- 临时传输
- 设备验证
- 自动清理

**自动热点**：

iPhone自动为其他设备提供热点：

**工作原理**：
```
Mac/iPad需要网络
  ↓
检测到iPhone
  ↓
自动连接（无需密码）
  ↓
使用网络
  ↓
自动断开
```

**优势**：
- 无需输入密码
- 自动连接
- 节省电量
- 安全可靠

**即时热点**：
- 快速连接
- 低延迟
- 自动管理

### 6.3 电话和短信

**在其他设备接听iPhone电话**：

**要求**：
- 同一Apple ID
- 同一Wi-Fi网络
- 启用功能
